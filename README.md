# Quick Draw ML 프로젝트

이 프로젝트는 **Quick Draw 데이터를 활용한 머신러닝 모델 학습 및 예측** 프로젝트입니다.  
사용자가 그린 그림 데이터를 기반으로 모델이 무엇을 그렸는지 예측하도록 구현했습니다.

---

## 📌 프로젝트 개요
- Quick Draw 데이터셋 활용
- 다양한 카테고리 그림 인식
- 머신러닝 모델 학습 및 평가
- 예측 결과 시각화

---

## 🛠️ 사용 기술
- Python
- Jupyter Notebook
- NumPy, Pandas
- scikit-learn, TensorFlow / PyTorch
- Matplotlib, Seaborn
